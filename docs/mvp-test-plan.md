# MVP 测试计划

## 算法测试

- 使用合成正弦波验证 G3、D4、A4、E5 的识别结果。
- 验证低置信度帧不会进入评分。
- 验证频率到音名和 cent 偏差换算。

## 小程序真机测试

- 设备：至少一台 iOS 微信、一台 Android 微信。
- 权限：首次授权、拒绝授权、设置页重新授权。
- 录音：开始、停止、切后台、中断恢复。
- 音高：空弦 G/D/A/E、简单音阶、安静环境、普通家庭噪声环境。
- 稳定性：连续检测 30 秒，观察卡顿、崩溃和内存异常。

## CloudBase 测试

- 当前环境 ID：`brain-game-6gtx0hei4de22731`。
- 创建 `practice_sessions` 集合。
- 保存一次练习记录。
- 历史页读取当前用户记录。
- 断网或权限错误时显示失败提示。

## 验收标准

- 用户可以完成：首页 -> 检测 -> 结果 -> 保存 -> 历史记录。
- 原始音频不保存、不上传。
- 异常状态不阻断页面返回和再次练习。
- 支付、限次、AI 点评不属于本 MVP 验收范围。
